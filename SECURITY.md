# Security

Never include personal tokens, passwords, session cookies, or private account data in public issues or pull requests.

For a sensitive vulnerability, use GitHub's private **Report a vulnerability** feature if it is enabled for this repository. If it is unavailable, open an issue requesting a private reporting channel without disclosing the vulnerability or any secret. No private contact address is configured in this document.

Include affected versions, impact, and reproduction steps using dummy credentials. The project does not promise a response deadline.

If a real credential has been exposed, revoke or rotate it through its provider. Deleting a public message alone does not invalidate a credential.
